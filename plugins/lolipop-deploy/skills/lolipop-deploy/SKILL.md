# ロリポップ！自動デプロイスキル

このスキルはロリポップ！レンタルサーバーへのデプロイを対話的にガイドする。

手順は公式が随時更新しているため、トリガーされるたびに最新版を取得して従う。

## 実行手順

1. 以下のURLから最新のデプロイ手順を取得する:

   ```
   WebFetch: https://lolipop.jp/ai/skills/skill.md
   prompt: "全内容をそのまま返してください。省略しないでください。"
   ```

2. 取得した手順に従い、ユーザーを対話的にガイドする

3. 手順の中でユーザーに情報を聞く場面では、一度に全部聞かず、1つずつ順番に聞く

4. 手順だけでは対応できない質問（料金プラン、サービスの特長、対応ツール、申し込み方法など）があれば、LPから情報を取得する:

   ```
   WebFetch: https://lolipop.jp/ai/skills/
   prompt: "全内容をそのまま返してください。省略しないでください。"
   ```

## 注意事項

- skill.mdの取得に失敗した場合は、LPも試す。両方失敗した場合はユーザーにURLを直接確認するよう案内する
- パスワードなどの認証情報は、手順に記載されたセキュアストレージ（macOS: Keychain、Windows: Credential Manager）にのみ保存する。平文ファイルへの保存は絶対にしない
- `rsync --delete` を使うデプロイ前には、必ずユーザーに確認を取る
